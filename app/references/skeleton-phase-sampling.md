# 骨骼均匀相位抽样与连续性审计

用于已选定的`100STYLE motion-data.json`合同：`inPlace`为逐帧3D关节数组，另有`frameIds / names / parents / dt`。当前工具不宣称支持任意BVH、GLB或其他工作台格式；先明确转换及来源，再使用。只观察或取样现有运动，不镜像肢体、不自动修循环、不重定向身体比例。

```sh
python3 scripts/skeleton_phase_sample.py --source /project/walk-study/motion-data.json --count 8 --out /project/eight-phase-audit.json
python3 scripts/test_skeleton_phase_sample.py -v
```

## 抽样与时序

默认源片段不包含重复终点。N个源采样的索引周期为N，8帧取`i*N/8`，相位为0至7/8，输出不再追加相位1.0或复制首帧。80个源采样取`[0,10,20,30,40,50,60,70]`；这表示时间均匀，不表示手足位移相等，更不强迫左右姿态完全对称。

源数据明确包含一个周期终点时，使用`--includes-endpoint`：索引周期改为N−1，保留终点作为最后一段插值的实际参考，但不重复导出它。该开关是作者声明，工具不凭两个姿态相近自动判断；报告仍比较首尾相对骨盆的关节点差异。

索引是整数时保留原`inPlace`姿态和准确源帧号。非整数时对相邻实际关节位置线性取样，记录参与的两个索引／帧号与权重；不伪造一个“实际BVH帧号”。仅在默认的无终点输入中允许最后一帧与第一帧之间按索引周期插值，并显式标为`wrappedInterpolation`。这种索引策略不证明源片段无缝；跨边界插值可能产生不自然的姿态，需要实际观察，不能把插值数当成新捕获或新绘帧数。

周期毫秒数由`period * dt * 1000`就近取整。对所有相位边界一次取整后相减，保留周期总长。1333ms、8帧分配为`[167,166,167,167,166,167,166,167]`。不会把原来的长停帧保留后再额外追加时间。

## 报告与检查

报告保存源文件hash、来源／许可元数据、原关节命名与父子关系、每个取样姿态和源索引。分别审计完整源片段及抽样片段的左右腕、踝、趾轨迹：手腕相对同侧肩膀与骨盆，脚相对骨盆。每条轨迹包含3D来源单位和严格E投影`[sourceZ,-sourceY]`。

`stepDistancesIncludingWrap`包括最后一帧到第一帧，另列内部最大步长、边界步长、最大跳变所在索引。相对轨迹会剔除共同根平移，避免把角色前进误判为摆臂。当前只比较位置，不认证速度连续、接触时刻、遮挡、腿部身份或无缝循环。独立查看08→01，不能仅检查01→08。

骨架数值正确之后，仍要在人物图上标记同一解剖侧的肩、腕、支撑鞋和摆动鞋，逐阶段核对它们相对身体轴的位置、前后层次与运动方向。不能只做头顶和脚底配准就宣称动作相符。长袖遮住手时不要把袖尖当腕；被裙子遮住的腿也不能凭画面左／右改写解剖左右。

## 时间抽样与人物对应分别检查

均匀时间抽样可以减少由不均匀驻留造成的跳变，但不能修正人物母图中画错的手腕位置，也不自动消除原片段的周期残差。先核对人物相对同侧肩膀的轨迹是否遵守来源的摆动方向，再诊断密度和相位；不能把原本小幅前摆扩成大幅反向摆动来追求表面对称。具体角色的来源帧号、数值、生成记录和失败证据留在该项目。

若改用已经制作成循环的其他动作，明确记录来源变更；不静默更换骨架，也不把首尾复制或反播往返冒充正常完整步行周期。
