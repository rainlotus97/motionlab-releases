# 图像提示词配方

需要生成完整姿态、扩展动作、换装/身份或修复素材时读取。将变量替换为本次任务事实；不把所有模板一次塞进每次请求，也不要求用户输入模式代码。

## 先给参考分配权威

| 参考角色 | 可以决定 | 不可以偷偷决定 |
| --- | --- | --- |
| 外观 `appearance` | 物种、脸、比例、固有颜色、已有附肢与身份特征 | 动作参考不能覆盖这些特征 |
| 画风 `style` | 笔触、材质、光照、精细度和表现方式 | 不自动复制画风参考的脸、服装或物种 |
| 姿态 `pose` | 肢体姿态、动作阶段、重心与镜头下的方向 | 不带入参考角色的身体比例、尾巴、衣装和身份 |
| 完整动作 `motion` | 已采用动作的相位、幅度与节奏；同身份时保留其体型观感 | 换人物时不覆盖新身份与解剖；不默认授权新动作或整套重画 |
| 衣装 `costume` | 服装结构、配饰和衣料；按任务决定颜色 | 不覆盖原角色解剖、五官、动作或镜头 |
| 版式 `layout` | 格尺寸、顺序、安全留白与标记 | 不把辅助线、编号和文字画进最终角色 |

同一张图可能承担多项权威，要明确说明。参考冲突时按用户本次指定的权威解决，不能静默混合。没有独立画风参考时延续外观图，不强制某一种风格、比例、绿幕或背景。

示例开头：

> 图 A 只负责角色身份与画风。图 B 只负责本次动作的姿态和接触关系，不复制 B 的物种、脸和服装。图 C 只负责衣装。保留 A 的四肢结构，衣装变化不得改变角色比例。

透明素材优先请求真实 alpha；工具或流程需要纯色背景时采用能可靠分离且不污染角色的颜色。背景取决于目标工作流，不把绿幕当普遍要求。生成结果必须检查实际透明通道，不能把棋盘格当透明。

已认可轻快萌宠完整动作、希望简单沿用并增补方向／衣装时，使用 [简洁萌宠完整帧配方](simple-pet-motion.md)；也含从零入口与坏格只采用目标完整姿态的方法。

从零角色计划镜像扩向时，提示中优先无饰品、居中或左右对称的帽饰／装饰，避免主动加入单侧草叶或挂件后再翻图；已有不对称身份仍按其自身左右侧保留并独立核对背面。

## 完整动作设计请求

用于首次角色/新动作的少量关键姿态，先证明动作成立：

```text
任务：为 {角色身份} 制作 {动作意图} 的完整角色关键姿态。
参考权威：{逐张写清 appearance/style/pose/costume/layout 的负责范围}。
镜头与用途：{朝向、透视、镜头距离、实际显示尺寸、原地或带位移}。
身体结构：{两足/四足/无足/特殊附肢}，保持 {身份与比例不变量}。
动作阶段依次为：{准备、执行、结果、恢复中实际需要的阶段}。
每个姿态说明：{姿态名、承重/接触、躯干与四肢变化、道具位置}。
道具：{形状与刚性部件}；握持时 {手/爪/口} 与 {握点} 连续接触。
配饰清单：{固定器物数量、挂点及角色自身左右侧}；遮挡不增加新器物，动作中新拿起的物品另列。
画出独特且可连接的完整姿态，不拆贴头、脚或双臂，不用重复同姿态代替动作。
统一镜头、画布与角色尺度，留足 {尾巴/武器/翼/耳} 的运动范围。
输出：{独立透明图或行列明确的图集}；无文字、编号、背景纹理或辅助线。
```

动作幅度应匹配身体结构和阅读尺寸。把“可爱、自然、流畅”具体化为姿态与变化；这些形容词本身不能说明要画哪些帧。

骨骼引导多格图时，使用[骨骼到母图的交接包](skeleton-to-spritesheet.md#可复用的生成交接包)：逐格描述同一肢体从前继到后继的方向、支撑与遮挡，而非只给孤立腕坐标。参考图和提示词不提供可验证的强制时序控制，实际输出仍须逐格与连续窗口验收。

## 根据缺口补真正的中间姿态

先检查现有相邻姿态，再只描述欠缺的阶段：

```text
外观权威为图 A，前一完整姿态为图 B，后一完整姿态为图 C。
生成二者之间的 {阶段/相位}，不是 B 或 C 的复制，也不是两图叠化。
承重从 {当前接触} 过渡到 {后继接触}；{摆动肢体} 沿 {轨迹} 经过。
{手/爪} 始终握住 {同一道具握点}，{刚性杆/刃/杯沿} 保持完整结构。
{头/躯干/尾巴} 的跟随幅度为 {动作合理范围}，不能任意改变身份比例。
仍输出完整角色，与相邻帧使用同一镜头、画布尺度和已约定动作根位置。
```

近似中位帧过多导致停顿时，先调整帧序或时长；中间位移过大才补姿态。不要每遇到卡顿就生成更多相似中位帧。

## 日常动作替换块

将以下动作描述插入完整模板，根据角色解剖改写。

- **喝水**：低头/取杯，移动到嘴边，明确口与水面/杯沿接触，小幅饮用，离开并放稳。四足不默认双手端杯；杯、口和爪的遮挡保持一致。
- **打盹**：眼睑变沉，重心降低，逐步卧下，胸腹轻呼吸，耳/尾偶有轻动。已卧下的脚、腹或臀接地稳定；醒来抬头与重新入睡分别有过渡。
- **起身招呼**：趴卧抬头，前肢撑起，后躯跟上，站稳后朝玩家转头，用空出的手/爪/原有附肢招呼，收回并恢复站姿。每个阶段说明实际支撑点。
- **任意任务**：描述对象在哪里、角色如何接近、通过什么接触完成、玩家何时看见结果、怎样收回。动物本来没有的手脚不要凭空添加。

## 移动或战斗替换块

```text
动作：{走/跑/跳/滑行/攻击/受击/闪避/收招/自定义}。
移动权威：{原地循环，或带明确根轨迹的动作}。
关键阶段：{按本动作列出，不套用无关脚步模板}。
接触表：{每阶段承重肢体、离地/落地、握持/释放、必要的遮挡}。
速度与力度：{可见的步幅、躯干变化、蓄力与恢复关系}。
镜头方向：{本轮制作方向}；{非对称衣装/持械手} 的身份保持一致。
如需特效：{独立表现层或已绘入角色帧}，不重复绘制已有运行时特效。
```

攻击的接触/释放帧由动作设计定义，生成图不决定真实伤害。输出需要事件表时，仅记录语义阶段与时间，交给项目的业务规则处理。

## 换装、换身份和多方向

**同身份换装**：

> 图 A 是动作与身份唯一权威；图 B 只提供新衣装。逐姿态保留 A 的解剖、脸、动作阶段、镜头和道具接触，仅替换服装及其合理的布料跟随。保留 {不能被衣装覆盖的身份标志}。不移动角色来适应背包或衣摆包围盒。

**换成另一萌宠/主角**：

> 新角色外观以图 A 为准。旧角色动作图 B 仅提供动作意图、阶段和镜头，不复制其物种、附肢、脸、衣装或比例。按新角色 {身体结构} 重新设计 {动作} 的支撑与接触；保留 {需要复用的语义节奏}，允许为新解剖调整步幅与幅度。

**扩展方向**：

> 以 {已确认外观与方向参考} 为准，制作 {新方向} 的 {动作}。保持镜头高度、比例、动作相位和左右手身份；按视角重新画前后遮挡及可见背面结构。{非对称细节} 不横向翻转。若背面结构尚未定义，先给完整姿态样板再扩展整套。

## 局部问题修复

```text
仅修复 {具体帧、具体位置与缺陷}。
正确关系应为 {肩肘腕连接/握杆接触/刚性杆连续/自然毛边/正确遮挡等}。
{明确区域} 以外保持原角色身份、画风、毛色/肤色、镜头、比例和动作语义。
输出修复后的完整角色帧；不要用大范围裁边、贴换脸/脚或整体调色掩盖问题。
相邻帧为 {参考}，修复后需能衔接；不要顺便改变已认可的其他动作。
```

工具支持遮罩时按需使用，但不能假设遮罩外一定逐像素未变；比较实际输出。若整帧重绘改变了过多外观，不强行贴回局部碎片，以完整姿态重新修复或撤回到最近可信版本。

不要把“干净边缘”写成削平毛发。说明应去除的是孤立杂点、旧背景污染或错误尖簇，同时保留自然毛边与原有颜色；检查透明度与色彩两者，避免抠边后出现灰边、缺脸或色差。

## 交付前核对提示的结果

按实际图片核查：参考权威是否被遵守、每帧是否真正独特、关节和握点是否连贯、身体尺度是否一致、接触与遮挡是否合理、完整帧是否越格。提示词写对不等于结果已通过。

如果图集排布与请求不符，先记录真实行列和单元范围，按观察结果提取；不盲切名义网格。把生成母图、实际采用帧、变换、时长及修复来源留作可复现记录。
