# 质量与最小修复

## 先区分四种坐标

源图像素、统一角色单位、导出画布像素、游戏世界坐标分别记录。不同返回分辨率通过source级像素密度归一，不能给每个姿态独立fit-bbox。所有动作的可见范围（含尾、头饰、武器、放下的杯子和合法离体特效）共同决定画布；不足时扩大共用画布并移动origin，而不是逐帧缩角色。

| 动作 | 合理锚点 | 不应强制 |
|---|---|---|
| 站立／扫地／持杯 | 承重脚或稳定身体根；次要接触点另记 | 用扫穗、杯子或武器最低点作脚线 |
| 原地步态 | 骨盆／身体根+按相位交替的承重足 | 两只脚每帧同位置、用眼睛强行固定全身 |
| 带位移的步态 | 同上，世界位移另有root track | 把场景移动烘进每格裁图后又由引擎移动一次 |
| 趴睡／四足休息 | 腹部或前爪的真实地面接触 | 套用站立脚底或把呼吸变成整体跳动 |
| 跳跃／飞行／攻击腾空 | 投影根或持续的骨盆根，可在源rect外 | 每帧落回同一脚线、为碰地拉长双腿 |

不把某角色的眼部阈值、肤色、身体比例或特定像素ROI写成通用自动识别器。自动检测可提示，实际物理接触与异常需看图；没有可靠标记时采用人工注释的锚点。

源图集中的角色可能没有站在名义格中心。整身横向跳位时，在同方向内按实际姿态注释稳定的头／颈／躯干特征，只平移整张完整人物；不要跨方向共用一组图集列中心，也不要用尾巴、迈出的脚、衣摆或道具影响的bbox重心代替身体中心。可以只修X并保留原Y起伏；主动摇头／转身则不能用眼睛强行锁定。标记采用哪个部位、源坐标、共用比例、原／新anchor、目标中心及镜像关系，原图变化后重新核对。

头／耳标记不漂移，只证明该标记稳定。还要核对它是否落在共同身体／支撑轴的正确位置，并横比头宽高、肩胯距离和头到尾外缘的关系；如果头尺寸不变而尾与躯干在收步帧收缩，整图平移或逐帧缩放都不能修好，应重画对应完整姿态。允许动作本身的挤压／转身时另按其意图判断，不把所有部位强行定死。

当用户明确要求统一母版高度，且源图来自不同生图批次时，可使用[公共配准工具](frame-registration.md)以相位目标头高、身体轴和承重足做整图等比校准。须同时校验头部／躯干跨度与视角偏差，不能只对齐头顶后拉腿接地。相同左右阶段成对检查，不能把一侧更低误当正常起伏。

身体前后幅度与高度要沿完整循环检查：先消除无意配准跳位，再看头颈／躯干相对支撑的轨迹，以及双半周期是否出现持续的高低或前后偏差，包含末→首。相机、比例、支撑与连续性是共性要求；自然bounce、透视和风格化幅度可以保留，不要求来回像素完全相等。骨骼仅作阶段／节奏参考时，依据可见支撑、肢体身份与观感验收，不用隐藏关节的逐点距离代替；用户要求精确转绘时再按冻结关节目标另验。

## 审图顺序

1. 源完整格：身份、头身比例、肢体数量、道具形状、手的占用。建立本外观的配饰清单：数量、固定挂点与角色自身左右侧；区分固定腰包和动作中拿起的布包。被遮住不等于不存在，后续帧不能凭空补出第二个挂包。
2. 装配对照：相同画布／倍率／背景下逐帧看脚、根、头脸、道具和衣装。看实际alpha与深浅两种背景，区分图中已画出的灰块和透明背景污染。
3. 最大伸展：攻击长武器、起身、长尾、抬杯、张翼都可能越格；不要只看中性站姿。
4. 播放：去程和回程分别看、首尾接缝、身体与道具轨迹、一次性动作收势。
5. 小尺寸：到用户目标CSS尺寸审，放大好看不等于小尺寸读得清；放大仅用于诊断。

自动hash／alpha／帧序检查证明文件技术性质，不证明解剖、观感、命中或用户接受。

连续性返修按[时间窗口门禁](skeleton-to-spritesheet.md#连续性检查的最小单位是时间窗口)查看修改格前后至少两格及正常速度全循环，另查首尾；只播放首尾片段可能遗漏改图后的邻缝。腕高最大差降低只是一维诊断，不能覆盖身体相对XY轨迹、前臂方向、相位及速度突变。用户指出仍不连贯即记录视觉未通过，不能继续用“待审”或已执行播放来代替结论。

镜像方向也逐帧检查身份。用独立正面、背面基准将饰物挂点转换到角色自身左右侧，并核对该视角的遮挡；不能凭画面左右、眼睛位置或翻图文件名认定正确。用户允许镜像姿态，不等于允许单侧饰物、惯用手或衣纹换边。新设计计划镜像时，在生成前落实对称／居中／无饰物方案；保留不对称时独立补画必要视角。当前样板已出错且用户授权修饰物时，需实际替换并播放复核受影响素材，不能只记录为未来提醒。

## 行走的交错验收

当用户要求交替行走时，先跟踪固定身份的左／右足，而非给两种轮廓命名为“接触／经过”。原地步态中，承重足应从身体前方连续经过髋下到后方，另一足离地后从后方经过承重腿到前方；半周期后交换。结合角色解剖、相机及衣摆遮挡审阅真实可见轨迹。仅左右轮流向前抬脚，仍可能缺少经过或回摆；帧数多、hash不同、播放段切换正确都不能证明交错成立。必要时用临时脚色或关节标记跟踪身份，并在正式素材里去除。

先验证一条代表性循环，再扩衣装／方向；慢放看两个经过与末首接缝。前后视透视深度不同，不能把侧面水平位移机械套到所有方向。行进预览的root速度须匹配步幅与周期，再核对承重足世界接触；不能让正确的原地腿循环被无关的场景横移速度破坏。

已有用户认可的同类动作时，先复用它的完整姿态、短腿／体型比例与节奏；方向扩展、换装或局部坏格围绕这套基准处理。不要为了技术诊断把已认可的轻快卡通跑动重做成长腿写实步态，或未经验证的新骨骼工程。诊断服务于用户要求的观感，不反过来改变动作风格。只有完整姿态路线确实不适用且任务需要时，才考虑新的真实绑定；骨长／足锁通过仍不代表实际皮肤与观感通过。

有手臂的双足跑动，逐帧跟踪肩／胸口与左右手，而非只看手在画布中的高度。消除整身平移后，手相对躯干应能读出前后摆动与交替相位，并与腿部相位相符；前／背视通过投影、相对肩位和遮挡判断，不能把侧面横向位移硬套过来。手臂只有同向上下跳，或完全依靠整身bounce制造“运动”，不能通过跑动验收。允许已认可的短促卡通幅度；需要修时补对应完整姿态，避免独立移动手掌造成断腕。物种、附肢或动作不同则按其真实结构与意图验收，不把双足摆臂变成所有动作的模板。

## 故障到修复范围

| 症状 | 先确认 | 优先修复 |
|---|---|---|
| 脚或身体左右滑 | 是否逐帧bbox居中；真实根位移是否重复应用 | 改共用尺度与根／接触锚点；不贴旧脚掩盖 |
| 肩肘与手不连 | 前臂是否围绕胸口整体转；绑定是否有真实父子关节 | 重画完整姿态或修真实骨骼约束；不要移一张手掌贴住 |
| 杆／剑折弯 | 上、中、下可见段是否共线，握点是否跟同一刚体 | 完整姿态中修直刚体及手腕；不分段拉伸柄 |
| 道具经过脸会消失 | 错误图层、旧头片遮盖还是源画缺失 | 修绘制遮挡／真实层次；不让手和工具无条件永远最前 |
| 中间明显停顿 | 近似姿态连续驻留、节奏不均还是缺少过渡 | 量每段停留；合并播放驻留、择一中位或补真实过渡 |
| 一侧瞬移 | 对应轨迹间距与段时长，而不只是总FPS | 时长按位移调整，必要时补这一侧的真实完整帧 |
| 脸缘有灰褐楔块 | 源画轮廓、残底、低alpha毛边还是显示缓存 | 仅异常局部，保留脸内侧与RGB；不能全脸硬切 |
| 一套衣装脸变色 | 衣装参考是否取代身份，或重画影响整个脸 | 回到身份权威；只修对应区域／衣饰，不顺带换光线 |
| 某帧多出包／武器／杯子 | 配饰数量、挂点、手的占用和遮挡关系 | 只修确实多出的那一帧，补原有衣料／背景；不能直接挖透明洞或重画整组 |
| 镜像或背面饰物换侧 | 角色自身挂点、正背面基准、遮挡及镜像适用性 | 在用户授权范围改为对称／居中／无饰物，或补画正确视角；实际修素材后再验收 |
| 跑动手臂只上下跳 | 手相对胸口／肩部的轨迹、左右相位及腿部配合 | 定向补画完整姿态的前后摆与交替，不以整身bounce或移动手掌代替 |
| 显示旧结果 | HTML、模块、CSS与图片是否各自缓存 | 查实际请求URL／解码尺寸并更新恰当版本；不要先重生图 |

## 局部轮廓清理

生成轮廓不佳不等于都能靠透明阈值解决。高alpha异常楔块与脸相连时，全局阈值／最大连通块无效；侵蚀alpha会同时削眼睫、细手指、杯柄和毛色边界。

高alpha主块也可能遗漏较透明但合法的耳冠、绒毛或饰物。出现凹口／双峰时，把原RGBA、颜色清理后、组件隔离后三阶段并排检查，先确认是哪层遮罩误裁；不要把提取错误当成需要再生图。只在该格已复核的小范围恢复原alpha软边，邻格残片另行隔离，保留RGB与其余角色像素。

若任务仅要求收回小段异常外缘，可用经过审阅的生成修复作为局部alpha参考，记录适用帧、ROI、配准、羽化与前后差异；保留原RGB并解码验证只在授权区域改变alpha。不得把这当作所有角色通用的脸型裁刀。若需要补画、改变表情或恢复丢失肢体，应绘制正确完整姿态，alpha缩减无法恢复内容。

不要默认删最大连通块之外的部分：抛出的球、杯盖、离身法术、独立衣带可能正是动作。保留原始母图，导出可重建；重复运行应从原始来源开始，不能在上次已清理文件上累积削切。

## 节奏与相似帧

用户指出“同一张又出现一次”时，逐级对照源姿态、manifest序列、runtime裁区、实际解码动图与播放器末首边界。区别有意驻留、同一姿态重复映射、编码额外首尾帧和语义相同的两张重画。相反腿身份的两次经过不能仅因轮廓接近就复用同一张；补出真实反相完整姿态再查闭环。hash不同不能证明相位不同，技术去重也不等于步态正确。

对齐后的相邻像素差只用于找候选：静止呼吸、眨眼前停顿、蓄力可能本来就很近似。先看动作意图与移动轨迹，再决定是否删一个播放位置。源独特帧数和播放段数分开报告，往返不重复停两次端点。

循环要看末→首；一次性要看准备→主要动作→收势→终态。动作变速不得悄悄改变游戏攻击时点或移动速度；需要改规则时进入原宿主的正式变更流程。
