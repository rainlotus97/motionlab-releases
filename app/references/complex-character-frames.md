# 复杂衣装角色：骨架引导的完整帧分支

用于成年比例、长裙、宽袖、披发、持械或大量前后遮挡，且用户希望保留精细立绘质感的逐帧动画。小短腿、简单轮廓、已成立的轻快动作走[轻量分支](simple-pet-motion.md)，不机械增加骨架、全身标记或写实步态。两条路线共用[多格母图与资源预算](sheet-authoring-and-budget.md)、来源与验收规则。

## 从已经认可的路线继续

用户满意骨骼运动、不满意切件变形时，骨架应作为**生成完整人物帧的姿态参考**。不能未经授权改走低模、从零绑定或给立绘拆腿扭裙，尤其不能把技术绑定成功当成用户要的精细画面。真正可用的现成绑定仍可沿用，但先看实际皮肤与衣发效果。

四张关键帧通常只验证角度、解剖关系、衣料逻辑和工作流。分别记录：`identityAccepted`、`keyposeAccepted`、`clothAccepted`、`registrationVerified`、`workflowFeasible`、`motionSmoothnessAccepted`、`runtimeVerified`，不用一个accepted吞并所有状态。用户说“整体可行但不够流畅”，只更新可行性，不能把四帧定为最终交付或直接固化为所有角色默认帧数。

## 骨骼参考的两种精度

骨骼图＋提示词→母图→序列帧的交接、工具能力边界和连续窗口检查见[共用流程](skeleton-to-spritesheet.md)。先预演实际抽样后的离散方案，不拿原高帧动作的流畅替代本次低帧方案验证。

沿用用户当前选择，并在制作记录中说明参考负责什么：

- **阶段／节奏参考**：继承接触、经过、交替支撑、摆臂方向、周期与首尾关系；按角色比例、相机和衣装设计合理的可见幅度。重点是完整人物连续自然，不要求每个腕、膝、踝落在目标骨架的同一像素，也不因长裙下无法确认的隐藏关节直接否决整格。
- **精确姿态转绘**：用户明确要求严格复现某骨骼取样时，按冻结目标核对肩肘腕、髋膝踝和遮挡；无法从画面确认的点记为不确定，不能宣称精确通过。几何偏差与衣料／观感分别记录。

两种精度都保留固定左右身份、合理解剖和支撑关系，不能用“风格化”解释断肢、错腿或突变。膝部是否明显弯曲取决于动作、角色结构、画风与可见性；帧率只影响时间采样密度。用户将目标从逐点复现调整为整体连贯时，保留原冻结来源并更新验收说明，不再以旧精度强制反复重画，也不把近似姿态称作严格匹配。

## 动作卡先于图片数量

1. 锁身份、体型、衣装结构、披发／束发、惯用手和固定饰物；参考图各自负责外观／动作／相机／布局。新方向不能继承旧方向的错误遮挡。
2. 固定相机高度、投影和朝向。明确人物自身Left/Right、画面左右、相机近远侧；不因为腿越过身体轴就交换身份。骨架颜色只是本项目约定，除色彩外写出L/R及支撑／摆动角色。
3. 定义一个循环的阶段表、各肢体身份、支撑／离地／经过／前伸、摆臂与足交接、躯干轨迹、首尾。动作参考的时间是目标，不代表生成图已经匹配那个时刻。
4. 锁目标显示尺寸、总周期、关键帧和后续8／16／24帧计划。写明源独特图数、播放段数、渲染刷新率，三者不同。
5. 生成优先考虑**一张多格完整母图**：行＝方向，列＝相位，或单方向按相位排满数行。每格仍是一张完整角色。空间／清晰度不够才按方向或连续相位分批；不是默认一图一帧。按[母图布局合同](sheet-authoring-and-budget.md)准备姿态格、顺序和留白。

## 长裙、宽袖、披发的具体约束

先让隐藏人体和支撑关系成立，再考虑布料。不能为了看清每条腿把长裙画成短裙或裤腿，也不能借裙子遮住错误关节。

- 支撑足在本相位承重；经过阶段通常接近身体下方，前后伸展阶段不要求两足都在根下。摆动足的高度和足尖方向由动作阶段决定，不把它拉到底线。
- 膝前可顶起宽而柔和的裙面，以下布料应有重力下垂与松量；不能沿弯曲小腿紧贴后缩，画成筒状裤管、脚踝卷口或高拱洞。衣料可以自然遮住大部分小腿，只露正常裙缘下需要的鞋部。
- 近侧与远侧裙片、足和手保持遮挡顺序。近侧腿摆动与远侧腿摆动不是同一张裙形换标签；不得整图镜像来伪造左右半周期。
- 两只手都要有结构来源，允许合理遮住，不允许无故消失或粘连。前后摆臂按肩—肘—腕与对侧腿配合，不能来回抬手凑动作。
- 披发跟随背部和惯性，不能忽然跑到胸前、改变总长度或逆向穿过肩膀；轻步行不自动加大风。头部平稳，不能用仰颈／头变大冒充呼吸或起伏。

修裙摆时，用户已确认的腿位和相位成为保留项；只改衣料垂落。模型仍可能改脸、手、足位或整身大小，必须检查真实结果。一次编辑错把经过足变成前伸足时，退回正确腿位的源图，不继续沿错稿累积修复。

## 工作台与处理顺序

- **母图／单格层**：原始生成图、提示词、实际工具、输出尺寸、alpha、hash、格ID与实际sourceRect。源图长期保留，采用格与失败格分开。
- **标记／配准层**：[公共配准工具](frame-registration.md)提供点击标记、撤销、导出JSON。显式标记身体轴、当前承重鞋底、可复核的头／颈／腰及角度参考。坐标来自审图；不能称为自动骨骼识别。
- **审阅层**：同画布并排、脚线／头高／中线、临时左右足颜色、骨架参考、正常速度／半速／逐帧、末→首。骨架叠加只是目标对照，不证明图像匹配。
- **冻结目标对比层**：用[共享对比页](studio-workbench.md#冻结方案与人物逐帧对照)将实际采用的方案快照逐格映射到人物frameID，同步观察并保存人工问题；不每次生图重写页面。源相位／原生帧贡献和人物编号分开，旧素材挂新目标时明确`historical-unmatched`，不能让相同编号暗示姿态一致。
- **运行资产层**：由确认的源格重建运行尺寸PNG／图集／manifest／动图。高分辨率母图不默认随游戏常驻；预览与运行加载预算分开。

先检查源画是否画错，再检查配准，再检查时序。用户要求修正母版时，不能只新增诊断按钮／比较页面／恢复旧版就结束；排查后必须实际修复授权范围里的源图，或明确具体未完成原因。

换源时重新核对整套动作。例如当前选择UAL八相位而旧母版来自100STYLE，周期和图数相同也不能沿用“已匹配”结论。用户明确采用新动作后，按本次参考精度修正完整人物；原腿位的保留项需针对新目标重新确认。阶段参考先核对交替支撑与可见轨迹，精确转绘再核对各关节目标。方案hash、源hash与配准数字通过只说明制作来源和几何检查，不替代人物姿态、衣料和首尾自然度的人工验收。

统一倍率与脚线并不保证身体同高。若生成批次实际像素尺度略有差异，按用户允许，以身体标记做有界的整图等比归一，检查头部／躯干比例；不能单拉腿、剪贴头或把所有格bbox填满。若真实身体比例不一致或相机转角错误，应重绘，不能放宽阈值假装过关。成对相位检查高度与身体前后幅度：两半周期应读成同一种步态，不能一半持续矮、另一半持续高，或突然前探／后缩。保留合理起伏与透视造成的差异，不强求两侧像素完全相等；行走、蹲伏、腾空不能共用一个固定头脚距离。

## 四帧到8／16／24帧

对需要自然行走的复杂角色，四帧作为阶段证明。先用8张验证交替支撑和完整脚轨迹，再以16张作为可评估的流畅候选；24张用于仍明显跳变的接触、脚交叉、裙发运动区间或目标表现需要。用户指定更高帧数时按其要求；并非所有动作机械停在16张。

- 先锁循环总时长和关键姿态的**实际阶段**，再把对应时间段拆开生成中间姿态。补帧后重分配原区间停留，使总周期不变；不能保留四帧的长停留，再把新增帧插上去导致变慢。
- 低帧版作为高帧时间轴的有意义子集设计，L/R接触与经过都保留。8→16可在各区间插入；16→24也可只补敏感区间，不要求均匀加一帧。
- 匀速素材可以等间隔采样；有明确接触、蓄力、命中或停顿时按事件与运动速度分配。首帧不再作为最后一张重复驻留。
- 光流／插值若工具支持，只能在已经正确的邻帧之间作为候选；脚交叉、宽袖和裙片遮挡需逐帧审查。不用插值修复错误解剖，重复帧也不是新画。
- 以1.333秒周期为例，8／16／24张均匀独特姿态约为6／12／18张每秒；并非8张图就是8fps，也不是页面60Hz就有60个动作姿态。最终以实际显示尺寸和速度审阅，不只盯帧数。

## 本次应避免再次发生的失败

| 失败 | 下次必须改变的做法 |
| --- | --- |
| 骨架满意，切件衣服与手变形 | 完整帧重绘优先；不为工具便利换成低模审美 |
| 红蓝／画面左右／近远混淆 | 保存固定解剖身份、相机、每阶段支撑和遮挡表 |
| 裙摆包着小腿卷成裤管 | 说明宽面受膝支撑后向下自由垂落，按真实衣料修源画 |
| 新的前伸图替掉经过格 | 按实际生成姿态核对相位，不照着参考帧号直接插入 |
| 换图同时把234ms变134ms | 外观替换不隐式改时序；相位真的变化时独立重编整段 |
| 脚底齐了但头高一侧低 | 核对身体跨度与同类相位高度；小幅整图等比校准，比例坏则重绘 |
| 反复改旧错误图仍越改越偏 | 保留用户认可的腿位／镜头，换干净参考，不累积错误源 |
| 单张通过被扩大成整段通过 | 分项验收，方法可行、四帧关键姿态、流畅度分别记录 |
| 一页排查代替正确母版 | 诊断服务于实际修图；用户授权修图就完成源图修复 |
| 四格里相反步实际同一侧 | 逐格跟踪肢体身份和摆臂，坏格独立返修，不靠编号解释 |
| 大母图和所有方向一起常驻 | 分离编辑／运行资产；先预算像素、驻留范围和图集页，再扩数量 |

这些是执行约束，不是保证“生图一把过”。本分支可复用的是参考权威、布局、标记、校准、实际修复和审阅流程；尚未验证的高帧数、多格稳定性与运行时方案要如实标为待试验。

## 过程与首尾连续性门禁

采用骨骼取样时读[骨骼均匀相位审计](skeleton-phase-sampling.md)，并按本次参考精度使用。对人物逐帧标注可见同侧腕／肩或身体轴，检查相邻方向、位移与停留时间，包含末→首；宽袖尖不能替代手腕。某一帧大幅后摆后下一帧直接前伸，应实际修两者间的完整姿态，不用换编号或提高FPS掩盖。批量编辑若改变已认可脚位，拒绝受影响格，转为单格局部编辑完整人物；保留其他格。语义阶段均匀重定时与均匀骨骼原时刻取样是两件事，记录当前图实际对应，不能混称严格姿态匹配。
