# 骨骼参考 → 人物母图 → 序列帧

在用户希望用已认可骨骼引导生图、一次生成多格或复用动作模板时读取。目标是复用动作合同、生成配方和共用工作台，不把某次失败图或某个人物的像素常量固化成合格模板。

## 这条路线的能力边界

可以把外观参考、选帧后的骨骼姿态图和逐格说明一起交给图像模型，生成完整人物母图，再确定性切格、配准、编排时序并导出序列帧／图集。**骨骼参考＋提示词是意图约束，不等于强制骨骼控制或跨帧时序约束**。数字坐标、红蓝线和“严格照做”也不能证明实际结果匹配。

先查当前接入的客户端及接口能力。若客户端仅暴露 `images/generations` 或 `images/edits` 的参考图与mask，便只能按这些能力设计；不能从提示词推断已经拥有独立骨骼条件、跨帧一致性或视频接口，也不能据此断言服务的其他接口永远不支持。`batch`只是组织请求，不自动建立帧间约束。用户指定随想或其他服务时沿用该选择，不能因视觉失败静默换服务；重试上限遵守所用技能和本次预算。

若任务要求精确逐点转绘，应先核实工具真正支持的空间条件能力，并通过代表性姿态验证；仅有参考图时如实标注为软引导，精确结果仍须核查。对阶段／节奏参考，允许合理幅度变化，但左右身份、支撑、镜头、比例和连续性仍要成立。

## 生成前先冻结可播放的离散方案

以下骨骼来源／hash及关节渲染只适用于采用骨骼的路线。已有认可完整姿态、无需骨架的短圆爪萌宠，直接冻结完整姿态表、格序和时长并离散预演；跳过第1、3步的骨骼合同和骨架图，不增加成人关节标注。

1. 读取用户采用的[抽样方案](sampling-plans.md)，保留来源hash、相机、体型档案、相位、真实插值贡献、顺序与逐段时长。
2. **播放本次实际4／8／16／24格的离散方案**，按最终时长看正常速度和首尾；不能拿原高帧连续骨骼的流畅代替低帧抽样验收。半周期成对是时间合同，不保证源动作幅度、投影或生成结果对称。问题先在来源、抽样、图像、配准和播放器中定位，别一律归因帧数少。
3. 用共用姿态渲染器输出与母图同格序的骨架图；统一投影、尺度和地面，写出角色自身L/R、近／远侧及颜色映射。具体颜色不写成通用解剖规则。
4. 为每格写最小动作表：`cellId → phase/time → support/swing → 同侧手臂前/中/后及运动方向 → 身体高度/倾斜 → 关键遮挡`。描述“从哪里经过到哪里”，不能每格只说一个静态姿势。人体相机与长裙规则见[复杂分支](complex-character-frames.md)，短圆爪角色用[轻量分支](simple-pet-motion.md)。

对手臂，检查同侧肩—肘—腕的连通与身体相对XY轨迹。前／后摆极值可短暂停顿，但两张中位很接近、下一张突然跨到远处会形成“停一下再跳”；不能只比较手在画布中的Y，也不能把幅度压到很小来让位移数字好看。前／背视通过投影和遮挡判断，不机械套侧面坐标。

## 可复用的生成交接包

复用已有工程格式，至少包含下面四类输入；缺什么就记录不确定项，不捏造已认可信息。

| 输入 | 负责的事实 |
| --- | --- |
| 外观参考 | 身份、原比例、衣装／发型、画风、已确定的方向外观 |
| 冻结姿态图与阶段表 | 骨架图或已认可完整姿态；同一相机下的相位、肢体身份、支撑、运动方向、时间 |
| 布局合同 | 每格范围、格序、身体轴、承重地面、安全区及实际像素预算 |
| 相邻完整人物参考（补帧／修复时） | 已成立的前后阶段与保留区域，不能取代本格目标相位 |

提示词只放本批必要信息，示例中的值均须由当前方案生成：

```text
输出一张{行×列}完整人物动画母图，格序严格按{cellId顺序}。
参考A负责身份、画风、衣装和身体比例；B负责各格姿态与相机；C负责布局。
方向={固定方向}，近侧={角色自身侧}，远侧={角色自身侧}；骨架颜色对应={映射}。
阶段表={逐格支撑/摆动、左右手前后位置与移动方向、身体起伏、关键遮挡}。
本批在完整周期中的前继={阶段}、后继={阶段}；循环末帧继续运动到首帧，不复制首帧。
每格相同角色尺度和固定相机；身体轴={位置}，承重地面={位置}，保留{相位起伏}。
{长裙垂落/披发发根与自由发梢/袖臂连通，或轻量角色的轮廓动作要求}。
保留{已认可部位与相位}；每格独立遵守阶段表，不把相邻格画成同一姿态。
全角色完整入格，留足{最大动作范围}，格间空白；不把骨架、文字和辅助线画进角色。
```

一张多格图有助于共用参考并减少调用，仍需按格核查；曾出现两格相邻修复把紧凑收步误画成长步，不能因其中一格正确采用整页。成本、有效像素和拆批准则见[母图与预算](sheet-authoring-and-budget.md)。不把“大图一次生成”承诺成“一次通过”。

## 确定性装配不能替代真实过渡

按实际返回尺寸、alpha和单元边界提取，保留原页hash、sourceRect、采用／拒绝格及模型元数据。编辑和mask都可能改变画布尺寸、身体位置、比例或其他肢体；换源后重新核对标记，不能只换hash沿用旧变换。

复用[公共配准](frame-registration.md)做整图等比尺度／平移、身体轴和当前承重足校准，保留合理身体起伏与摆动脚离地。不按逐格bbox居中，不拉腿贴手。**切格、导出序列帧或提升播放FPS不会生成缺失动作**；错相位需要修正确姿态，确实缺过渡才补完整人物帧。通用切格和配准可以自动化，语义判断不能由文件成功代替。

## 连续性检查的最小单位是时间窗口

- 修第k格后，查看它前后至少两格的连续窗口（循环索引回绕），多格修复取窗口并集；正常速度全循环和逐帧／半速诊断都看。**首尾接缝审查与修改格邻域审查是两项**：例如07→08→01→02看过首尾，仍未覆盖修改02后的02→03。
- 同时核查身体相对XY轨迹、肩肘腕角度变化、手脚相位、遮挡、相邻时长及去／回程幅度。`位移/该段时长`可辅助定位速度突变，换向减速／极值停顿可以合理；不要要求每段位移相等。人工点有遮挡与估计误差，保留不确定性，不套某角色固定px阈值。
- 逐格核对实际输出，分清`targetPhase`和可观察的`actualPose`；编号、方案hash和对称抽样不证明人物匹配。正确骨骼、技术配准、腕高最大差变小和“播放器运行过”均不能替代整体流畅判断。
- 同一问题修完又出现在邻格时，退回完整窗口的阶段／轨迹设计；检查是相位重复、幅度不均、错图还是时长不符，再决定最小改图批次。不要不断单格重画，把跳变沿循环搬家。保持冻结方案；调整实际时序须说明原因，不改标签伪装匹配。
- 用户明确反馈仍不连贯时，将`motionSmoothnessAccepted`记为false并记录失败；不能继续只写“待审”。用户要求停止则不再生成或补帧。技术通过、流程可行、局部改善、最终视觉接受分别保存。

## 什么可以成为模板

可复用：来源与参考权威、适合体型的抽样方案、布局／相位表生成方法、提示词变量、确定性装配、同一工作台及验收方法。只有经实际播放和对应验收的素材／配方才标为已验证；“流程可行”的四帧或仍不连贯的八帧保留为实验，不能作为通用金样。

先验证姿态、接触与连续轨迹，再按需要增加独特过渡帧；不把8→16→24当成自动修错。源母图仅用于制作，运行包按目标尺寸、透明trim、图集和按需驻留控制像素预算；合并成一张文件不自动节省解码内存。交付复用[既有工作台](studio-workbench.md)，不为每次出图另造演示页。
